# EMBER RUN — проектные инструкции

Браузерный автораннер-платформер: Canvas 2D 960×540, пиксельные ассеты, процедурный мир.
Герой с фиксированной X бежит слева направо; прыжок адаптивный, есть удар и парирование с отражением снарядов.

## Запуск и проверка

- Двойной клик по `index.html` (работает через `file://`).
- Либо `python -m http.server 8000` из корня и открыть `http://localhost:8000`.
- Отладочный хук: `window.__EMBER__` — `start()`, `step(seconds)`, `perk(type)`, `addPerkObject(x,y)`, `pattern(name)`, `setLevel(n)`, `hurt()`, `state`.
- Паттерны для проверки: `spike`, `slime`, `bat`, `saw`, `platform`, `orb`, `batwave`, `charger`, `chargerspike`, `spitter`, `spitterbat`.

## Архитектура

- `js/game.js` — состояние, фиксированный шаг 1/60, физика, спавнер, бой, отрисовка, HUD.
- `js/audio.js` — процедурные SFX и 16-шаговый синтвейв-луп; громкость/темп зависят от уровня.
- `css/style.css`, `index.html` — сцена 16:9, HUD, меню/пауза/финал, тач-управление.
- `tools/prepare_assets.py` — генерация спрайт-стрипов и тонированных слоёв фона.

## Правила дизайна (выводы агента-оценщика)

1. **Хитбокс обязан совпадать с силуэтом.** Шипы проверяются по треугольникам, а не по общему прямоугольнику; не возвращать прямоугольные коллайдеры для визуально пустых зон.
2. **У каждой угрозы должен быть телеграф.** Таран-кабан приседает и светится ~0.46 с до рывка; плеватель раздувает рот перед плевком. Новые враги без телеграфа не добавляются.
3. **Читаемость важнее красоты.** Тёмные силуэты врагов получают тёмный ореол/цветной glow, чтобы не растворяться в лесу. Герой и угрозы всегда ярче фона.
4. **Фиксированная X — не ломать.** Глубина создаётся таймингом, выбором маршрута (платформа/земля), парированием и перками, а не свободным движением.
5. **Парирование должно оставаться нужным.** Оно не должно быть самым простым действием: следить за радиусом, окном и наградой; отражённые снаряды должны убивать.
6. **Сложность не замирает.** После новых врагов нужны новые комбинации, а не только рост скорости; ночь и музыка должны успевать раскрыться в обычном забеге.
7. **Не размывать ядро.** Никаких новых систем, если они не усиливают цикл «бег → угроза → прыжок/удар/парирование → награда».
8. **Сначала честность и читаемость, потом глубина, потом полировка.**

## Текущее состояние (2026-10-29)

- Шипы: коллизия по профилю зубьев; прыжок над коротким зубом больше не засчитывается как попадание.
- Враги: слизень и мышь зеркалятся горизонтально; добавлены таран-кабан (телеграф → рывок) и плеватель кислоты (навесные парируемые плевки).
- Анимации: squash-stretch слизня, наклон/взмах мыши, процедурная анимация новых врагов, пыль из-под ног героя.
- Музыка: синтвейв 112–141 BPM, бочка 4/4, оффбит-бас, арпеджио, пэды, райзер; темп растёт с уровнем.
- Оценщик рекомендовал на будущее: сделать парирование требовательнее (радиус ~80, окно ~0.16 с, бонус за perfect), продлить игру после 18 уровня, поправить перекрытие перков с тач-кнопками и safe-area на мобильных.
